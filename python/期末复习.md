# 期末复习
# Python 核心数据结构详解：列表、元组、字典

这三大容器是 Python 的基石。复习时请重点关注它们的**可变性 (Mutability)** 和 **底层实现**。

## 1. 列表 (List)

**“最灵活的动态数组”**

* **符号**：`[]`
* **特性**：**有序**、**可变** (Mutable)、**允许重复**、**可存不同类型**。
* **场景**：几乎所有需要存储一堆数据的场景，尤其是数据内容经常变化的。

### 1.1 核心操作

```python
# 1. 创建
my_list = [1, "Hello", 3.14, [100, 200]]

# 2. 增 (Add)
my_list.append("end")       # 在末尾添加一个元素 (最快)
my_list.insert(0, "start")  # 在指定位置插入 (性能较差，涉及内存移动)
my_list.extend([4, 5])      # 拼接另一个列表

# 3. 删 (Remove)
my_list.pop()       # 弹出最后一个元素 (常用)
my_list.pop(1)      # 弹出指定索引元素
my_list.remove("Hello") # 按值删除第一个匹配项 (慢)
del my_list[0]      # 关键字删除

# 4. 改 (Modify)
my_list[0] = 999

# 5. 切片 (Slicing) - [start:end:step]
# 重点：切片会返回一个新的列表对象
nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])   # [1, 2, 3] (左闭右开)
print(nums[::-1])  # [5, 4, 3, 2, 1, 0] (倒序神器)
```

### 1.2 进阶技巧：列表推导式 (List Comprehension)

这是 Pythonic 代码的标志，用来替代简单的 for 循环。

```python
# 生成 0-9 的平方列表
squares = [x**2 for x in range(10)]
# [0, 1, 4, 9, ..., 81]

# 带筛选条件
evens = [x for x in range(10) if x % 2 == 0]
# [0, 2, 4, 6, 8]
```

## 2. 元组 (Tuple)

**“不可变的列表”**

* **符号**：`()`
* **特性**：**有序**、**不可变** (Immutable)、**允许重复**。
* **场景**：
    1.  **数据安全**：不希望数据被意外修改（如配置参数）。
    2.  **字典的键**：因为不可变，所以元组可以当字典的 Key，列表不行。
    3.  **函数返回**：函数返回多个值时，本质上就是返回一个元组。

### 2.1 核心操作

由于不可变，它没有 `append`, `pop` 等修改方法，只有查询方法。

```python
t = (10, 20, 30, 20)

# 1. 查
print(t[0])         # 索引
print(t.count(20))  # 统计出现次数
print(t.index(30))  # 查找索引位置

# 2. 坑点：单元素元组
t1 = (1)    # <class 'int'> 这是整数 1
t2 = (1,)   # <class 'tuple'> 这才是元组
```

### 2.2 杀手级特性：解包 (Unpacking)

```python
# 交换变量 (本质是元组解包)
a, b = 1, 2
a, b = b, a 

# 接收多个返回值
def get_point():
    return 100, 200 # 返回的是 (100, 200)

x, y = get_point()
```

## 3. 字典 (Dictionary)

**“键值对的哈希表”**

* **符号**：`{key: value}`
* **特性**：**无序** (3.7+ 版本保留插入顺序，但逻辑上视作无序)、**可变**、**Key 必须唯一且不可变**。
* **底层**：Hash Map (哈希表)，查找速度极快，是 O(1) 复杂度。

### 3.1 核心操作

```python
d = {"name": "Jerry", "age": 18}

# 1. 增/改
d["job"] = "Coder"      # Key 不存在则新增
d["age"] = 19           # Key 存在则修改

# 2. 查 (重点)
print(d["name"])        # 如果 Key 不存在，报错 KeyError (不推荐)
print(d.get("salary"))  # 如果 Key 不存在，返回 None (推荐)
print(d.get("salary", 0)) # 提供默认值 0

# 3. 删
d.pop("age")            # 删除并返回值
del d["name"]

# 4. 遍历
for k, v in d.items():  # 同时遍历键和值
    print(k, v)
```

### 3.2 字典推导式

```python
# 快速互换 Key 和 Value
old_d = {"a": 1, "b": 2}
new_d = {v: k for k, v in old_d.items()}
# {1: 'a', 2: 'b'}
```

## 4. 三大结构对比速查 (面试必背)

| 特性 | 列表 (List) | 元组 (Tuple) | 字典 (Dict) |
| :--- | :--- | :--- | :--- |
| **符号** | `[]` | `()` | `{}` |
| **可变性** | 可变 (Mutable) | **不可变** (Immutable) | 可变 |
| **有序性** | 有序 | 有序 | 3.7+ 有序 / 逻辑无序 |
| **底层实现** | 动态数组 | 静态数组 | 哈希表 (Hash Table) |
| **查找速度** | O(n) (慢) | O(n) (慢) | **O(1) (极快)** |
| **Key 要求** | 无 | 无 | **必须是不可变类型** |
| **典型用途** | 存一堆数据 | 存配置/坐标/多返回值 | 存映射关系/对象属性 |

### 什么时候用谁？
* 需要频繁修改数据、排序？ -> **列表**
* 数据是固定的（如星期、月份），或者用来当字典 Key？ -> **元组**
* 需要通过名字（Key）快速查找数据？ -> **字典**

# Python 面向对象编程 (OOP) 详解

面向对象的核心思想是将数据和操作数据的方法捆绑在一起，形成“对象”。复习 OOP，重点在于理解 **类与对象的关系** 以及 **三大特性**。

## 1. 核心概念：类 (Class) 与 对象 (Object)

* **类 (Class)**：**图纸/模具**。它定义了一类事物的抽象特点（属性）和行为（方法）。
* **对象 (Object)**：**实物/实例**。根据图纸造出来的具体东西。

**比喻**：
* `Car` (类) 是汽车的设计图纸。
* `my_tesla` (对象) 是一辆真实的、停在你家车库的特斯拉。

### 1.1 基本语法

```python
class Dog:
    # 1. 类属性 (大家共有的)
    species = "Canis"

    # 2. 初始化方法 (构造函数)
    # self 代表对象本身 (谁调用就是谁)
    def __init__(self, name, age):
        self.name = name  # 实例属性 (每个对象独有的)
        self.age = age

    # 3. 实例方法 (行为)
    def bark(self):
        print(f"{self.name} is barking: Woof!")

# 实例化 (造出一条狗)
dog1 = Dog("旺财", 3)
dog2 = Dog("来福", 5)

dog1.bark()  # 输出: 旺财 is barking: Woof!
```

## 2. 三大特性 (核心考点)

### 2.1 封装 (Encapsulation)

**“对内自我管理，对外隐藏细节”。**
你不希望别人直接修改你的银行余额，而是通过 `deposit()` 方法来修改。

* **私有属性**：在变量名前加两个下划线 `__`。
* **作用**：防止外部直接访问或篡改。

```python
class Account:
    def __init__(self, balance):
        self.__balance = balance  # 私有属性，外部无法直接访问

    def get_balance(self):
        return self.__balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount

acc = Account(1000)
# print(acc.__balance)  # 报错！无法访问
print(acc.get_balance()) # 成功，通过接口访问
```

### 2.2 继承 (Inheritance)

**“子承父业，拒绝重复造轮子”。**
子类可以自动拥有父类的属性和方法，还可以增加新的功能或修改已有的功能。

#### 2.2.1 基础继承与扩展
子类直接继承父类的方法，并添加新方法。

```python
class Animal:
    def eat(self):
        print("Eating...")

# Dog 继承自 Animal
class Dog(Animal):
    def bark(self):
        print("Woof!")

d = Dog()
d.eat()   # 调用父类方法 -> Eating...
d.bark()  # 调用子类方法 -> Woof!
```

#### 2.2.2 方法重写 (Override) 与 对象调用
如果子类定义了与父类**同名的方法**，子类方法会覆盖父类方法。

**实战演示：重写、创建对象与调用**

```python
class Father:
    def __init__(self, name):
        self.name = name  # 实例属性
        
    def speak(self):
        print(f"{self.name} says: I am the father.")

class Son(Father):
    # 重写父类的 speak 方法
    def speak(self):
        print(f"{self.name} says: I am the son, and I overrided this method.")

# 1. 创建对象 (实例化)
# Son 继承了 Father 的 __init__，所以需要传 name
s = Son("Mike") 

# 2. 通过对象调用属性
print(s.name)  # 输出: Mike (继承自父类的属性)

# 3. 通过对象调用方法
s.speak()      # 输出: Mike says: I am the son... (调用的是子类重写后的方法)

# 4. 强制调用父类被重写的方法 (使用 super)
# 通常在类定义内部使用，但在外部也可以这样理解逻辑
super(Son, s).speak() # 输出: Mike says: I am the father.
```

**super() 关键字**：用于在子类中调用父类的方法（通常用于扩展 `__init__`）。

### 2.3 多态 (Polymorphism)

**“一种接口，多种形态”。**
不管你是猫还是狗，只要你有 `speak()` 方法，我就能让你叫。在 Python 中，这被称为 **鸭子类型 (Duck Typing)** —— “如果它走起来像鸭子，叫起来像鸭子，那它就是鸭子”。

```python
class Cat:
    def speak(self):
        print("Meow")

class Dog:
    def speak(self):
        print("Woof")

def let_it_speak(animal):
    # 只要传入的对象有 speak 方法，就能运行，不需要管它具体是什么类
    animal.speak()

let_it_speak(Cat()) # Meow
let_it_speak(Dog()) # Woof
```

## 3. 魔术方法 (Magic Methods)

Python 的类之所以强大，是因为有一堆内置的 `__xx__` 方法。

| 方法 | 触发时机 | 用途 |
| :--- | :--- | :--- |
| **`__init__`** | 创建对象时 | 初始化属性 |
| **`__str__`** | `print(obj)` 或 `str(obj)` 时 | 返回对象的描述字符串 (给用户看) |
| **`__repr__`** | 在终端直接输入 `obj` 时 | 返回对象的官方描述 (给开发者看) |
| **`__len__`** | `len(obj)` 时 | 定义对象的长度 |
| **`__call__`** | `obj()` 时 | 让对象像函数一样被调用 |

**实战示例**：

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    # 定制打印显示
    def __str__(self):
        return f"《{self.title}》"

    # 定制长度
    def __len__(self):
        return self.pages

book = Book("Python指南", 300)
print(book)      # 输出: 《Python指南》 (而不是 <__main__.Book object...>)
print(len(book)) # 输出: 300
```

## 4. 类属性 vs 实例属性

这是新手最容易混淆的地方。

```python
class Player:
    server = "CN"       # 类属性 (所有玩家共享)
    def __init__(self, name):
        self.name = name # 实例属性 (每个玩家独有)

p1 = Player("A")
p2 = Player("B")

# 修改类属性，所有人都变了
Player.server = "US"
print(p1.server) # US
print(p2.server) # US

# 坑点：如果你通过实例去修改类属性，其实是给该实例创建了一个同名的实例属性！
p1.server = "EU" 
print(p1.server) # EU (p1 独有的)
print(p2.server) # US (依然是类的)
```

## 5. 总结速查表

| 概念 | 关键词 | 一句话解释 |
| :--- | :--- | :--- |
| **类** | `class` | 造对象的图纸 |
| **对象** | `instance` | 造出来的实物 |
| **self** | `self` | 对象自己 (谁调用方法，self 就是谁) |
| **私有** | `__var` | 外部勿动 |
| **继承** | `class B(A)` | B 是 A 的儿子 |
| **多态** | Duck Typing | 不管你是谁，只要能用就行 |
| **魔术方法**| `__str__` | 让对象能被 print, len, add 等内置函数操作 |

# Python 变量命名规范详解 (基于 PEP 8)

在 Python 中，命名不仅仅是给变量起个名字，更是代码可读性的核心。Python 社区有着一套通过 **PEP 8** 确立的“官方”审美标准。

## 1. 基础硬性规则 (语法层面)

如果不遵守这些，程序会**直接报错**。

1.  **组成**：只能包含字母（a-z, A-Z）、数字（0-9）和下划线（_）。
2.  **开头**：**不能以数字开头**。
    * ✅ `user1`
    * ❌ `1user`
3.  **敏感性**：**区分大小写**。
    * `name` 和 `Name` 是两个不同的变量。
4.  **关键字**：不能使用 Python 的保留字（如 `class`, `def`, `if`, `import` 等）。

## 2. PEP 8 风格规范 (核心必读)

Python 的命名风格主要分为四种：
1.  **蛇形命名 (snake_case)**：全小写，单词间用下划线连接。
2.  **大驼峰命名 (PascalCase)**：每个单词首字母大写。
3.  **全大写 (UPPER_CASE)**：全大写，单词间用下划线连接。
4.  **驼峰命名 (camelCase)**：第一个单词小写，后面首字母大写（Python 中极少使用，除非为了兼容旧库）。

### 2.1 不同场景的命名对照表

| 场景 | 规范风格 | 示例 | 备注 |
| :--- | :--- | :--- | :--- |
| **变量 (Variables)** | `snake_case` | `user_name`, `item_count` | 最常用 |
| **函数 (Functions)** | `snake_case` | `get_user_info()`, `calculate_tax()` | 动作+名词 |
| **方法 (Methods)** | `snake_case` | `instance.save_data()` | 同函数 |
| **类 (Classes)** | `PascalCase` | `UserProfile`, `CarEngine` | **首字母大写** |
| **常量 (Constants)** | `UPPER_CASE` | `MAX_CONNECTIONS`, `PI` | 通常定义在文件顶部 |
| **模块 (Modules)** | `snake_case` | `my_script.py`, `utils.py` | 尽量短小 |
| **包 (Packages)** | `snake_case` | `urllib`, `requests` | 不推荐使用下划线 |

### 2.2 实战示例

```python
# 1. 常量 (全大写)
DEFAULT_TIMEOUT = 60

# 2. 类 (大驼峰)
class DatabaseConnection:
    # 3. 方法 (蛇形)
    def connect_to_server(self):
        # 4. 变量 (蛇形)
        server_ip = "127.0.0.1"
        is_connected = True
        return is_connected

# 5. 函数 (蛇形)
def main():
    db = DatabaseConnection()
    db.connect_to_server()
```

## 3. 下划线 `_` 的特殊含义 (进阶)

在 Python 中，下划线的位置非常有讲究，它代表了变量的**可见性**和**特殊用途**。

### 3.1 单下划线开头 `_var`
* **含义**：**弱“内部使用”标识**。
* **作用**：告诉程序员“这是一个内部变量，请勿在外部直接使用”。
* **限制**：`from module import *` 时，不会导入以 `_` 开头的变量。

```python
class Test:
    def __init__(self):
        self.name = "Public"
        self._age = 18  # 建议仅在类内部或者子类中使用
```

### 3.2 双下划线开头 `__var`
* **含义**：**类私有成员 (Private)**。
* **作用**：触发 Python 的**名称改写 (Name Mangling)** 机制，防止子类意外覆盖父类的属性。
* **原理**：解释器会把它改名为 `_ClassName__var`。

```python
class Test:
    def __init__(self):
        self.__secret = "Password" # 外部无法通过 .__secret 访问
```

### 3.3 双下划线开头和结尾 `__var__`
* **含义**：**魔术方法 (Magic Methods)**。
* **作用**：Python 系统保留的特殊方法。
* **规则**：**绝对不要**自己发明这种名字的变量，只使用系统已有的（如 `__init__`, `__str__`, `__file__`）。

### 3.4 单下划线结尾 `var_`
* **含义**：**避嫌**。
* **作用**：当你想用的变量名恰好是 Python 关键字时，加个下划线来区分。

```python
# class 是关键字，不能用，所以用 class_
def create_student(name, class_):
    pass
```

### 3.5 单独一个下划线 `_`
* **含义**：**无关紧要** / **占位符**。
* **作用**：表示我不关心这个变量的值。

```python
# 循环 10 次，但不需要用到索引 i
for _ in range(10):
    print("Hello")

# 元组解包，只想要第一个和最后一个
start, _, end = (1, 2, 3)
```

## 4. 命名避坑指南 (Bad Smells)

### 4.1 毫无意义的单字母
* ❌ `a = 10`, `b = 20`, `c = a * b`
* ✅ `width = 10`, `height = 20`, `area = width * height`
* **例外**：在数学计算中 `x, y, z` 或循环中 `i, j, k` 是可以接受的。

### 4.2 容易混淆的字符
永远不要使用单字符 `l` (小写 L), `O` (大写 o), `I` (大写 i) 作为变量名。
* `l` 和 `1` 很难分。
* `O` 和 `0` 很难分。

### 4.3 中文拼音或 Chinglish
* ❌ `daka` (打卡), `jiage` (价格)
* ✅ `clock_in`, `price`
* 代码是给世界看的，请使用英文。

### 4.4 类型标记 (匈牙利命名法)
Python 是动态类型语言，**不需要**在变量名中把类型写出来。
* ❌ `name_str`, `age_int`, `user_list` (虽然 list 后缀有时为了强调是列表可用，但尽量避免)
* ✅ `name`, `age`, `users` (复数暗示了它是列表)

### 4.5 词不达意
* ❌ `temp`, `data`, `info`, `val` (除非作用域极小，否则这些名字等于没起)
* ✅ `user_profile`, `raw_response`, `input_value`

## 5. 总结

1.  **类名**用 `PascalCase` (大驼峰)。
2.  **变量、函数**用 `snake_case` (小写+下划线)。
3.  **常量**用 `UPPER_CASE` (全大写)。
4.  私有属性加 `_` 或 `__` 前缀。
5.  **变量名 = 含义**。名字越准确，注释就可以写得越少。

# 详解 Python 实现 1 到 10 的求和

在 Python 中实现 1 到 10 的求和（即 $\sum_{i=1}^{10} i = 55$）有多种方式。通过这个简单的需求，我们可以复习 Python 的**循环控制**、**内置函数**以及**算法思维**。

## 1. 基础流派：for 循环 (Standard Way)

这是所有编程语言通用的逻辑，适合初学者理解“累加”的过程。

```python
total_sum = 0
for i in range(1, 11):
    total_sum += i
print(total_sum)
```

### 核心细节解析
1.  **`range(1, 11)`**：
    * **左闭右开**：这是 Python 的铁律。`1` 是起始值（包含），`11` 是结束值（**不包含**）。
    * 如果你写 `range(1, 10)`，结果只能加到 9，总和会变成 45。
2.  **`+=` 运算符**：
    * `total_sum += i` 等同于 `total_sum = total_sum + i`。
3.  **变量命名**：
    * 根据 PEP 8，变量名推荐使用 `total_sum` 这样有意义的小写单词，避免使用单字母 `s` 或无意义的 `a`。

## 2. 优雅流派：sum() 函数 (Pythonic Way)

这是 Python 区别于 C/Java 的地方，极度简洁。在实际工作中，**这是首选方案**。

```python
result = sum(range(1, 11))
```

### 核心细节解析
* **`sum(iterable)`**：这是 Python 的内置函数，它接受一个可迭代对象（如列表、元组、range对象），并计算所有元素的和。
* **效率**：`sum()` 底层由 C 语言实现，比我们在 Python 层面写 `for` 循环要快得多。

## 3. 逻辑流派：while 循环

适合练习“状态控制”和“终止条件”。

```python
total_sum = 0
num = 1
while num <= 10:
    total_sum += num
    num += 1
```

### 核心细节解析
* **手动控制变量**：不同于 `for` 循环自动处理迭代，`while` 必须手动初始化 `num = 1` 并在循环内部手动 `num += 1`。
* **死循环风险**：如果忘了写 `num += 1`，程序将永远卡在 `1 <= 10` 的条件中，导致死循环。

## 4. 极速流派：高斯求和公式 (Math Way)

如果让你计算 1 到 1 亿的和，用循环会比较慢，用数学公式是瞬间完成。

$$Sum = \frac{n \times (1 + n)}{2}$$

```python
n = 10
result = (1 + n) * n // 2
```

### 核心细节解析
* **时间复杂度**：O(1)。无论 n 是 10 还是 100 亿，计算时间都是一样的。
* **`//` 整除**：Python 中 `/` 得到的是浮点数（如 55.0），使用 `//` 可以直接得到整数 55。

## 5. 函数式流派：reduce

适合习惯函数式编程（如 Lisp, Haskell）的开发者，或者需要自定义复杂累加逻辑（比如累乘）的场景。

```python
from functools import reduce

# lambda x, y: x + y 是一个匿名函数，表示将两个数相加
result = reduce(lambda x, y: x + y, range(1, 11))
```

### 核心细节解析
* **原理**：`reduce` 会取出序列的前两个元素进行 `lambda` 运算，将结果与第三个元素运算，依此类推。
    * 第 1 步：1 + 2 = 3
    * 第 2 步：3 + 3 = 6
    * 第 3 步：6 + 4 = 10 ...
* **注意**：在 Python 3 中，`reduce` 被移到了 `functools` 模块中，不再是内置函数。

## 总结：该用哪种？

| 场景 | 推荐方式 | 理由 |
| :--- | :--- | :--- |
| **日常工作 / 面试** | **`sum(range(1, 11))`** | 代码最少，可读性最强，不易出错。 |
| **初学逻辑** | `for` 循环 | 理解程序如何一步步执行。 |
| **超大数据量** | 数学公式 | 性能要求极高时使用。 |
