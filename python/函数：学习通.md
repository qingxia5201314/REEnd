# Python 程序设计试题解析

## 一. 判断题

1.  **题目**：`readline()` 方法每次调用都会从文件开头读取一行数据。
    * **答案**：❌ (错)
    * **解析**：`readline()` 方法是从当前文件指针（光标）所在的位置开始读取一行，而不是每次都从开头读取。读取后文件指针会移动到下一行开头。

2.  **题目**：Python中全局变量可以在函数内部直接修改。
    * **答案**：❌ (错)
    * **解析**：在函数内部读取全局变量是可以的，但如果要**修改**（重新赋值）全局变量，必须使用 `global` 关键字声明，否则 Python 会将其视为一个新的局部变量。

3.  **题目**：匿名函数 `lambda` 可以包含多条语句。
    * **答案**：❌ (错)
    * **解析**：Python 的 `lambda` 函数设计简洁，其函数体只能包含**一个表达式**，不能包含多条语句或复杂的逻辑控制块。

4.  **题目**：函数的文档字符串必须使用三引号包裹。
    * **答案**：✅ (对)
    * **解析**：虽然技术上单引号字符串也能作为 docstring，但根据 PEP 257 规范和 Python 惯例，文档字符串（Docstring）应始终使用三引号（`"""..."""`），以便支持多行文本。

5.  **题目**：`open()` 函数的 `encoding` 参数用于指定文件的打开模式。
    * **答案**：❌ (错)
    * **解析**：文件的打开模式由 `mode` 参数指定（如 'r', 'w'）。`encoding` 参数是用来指定文件的**字符编码格式**（如 'utf-8', 'gbk'）。

6.  **题目**：Python函数的返回值只能是单个值，不能同时返回多个值。
    * **答案**：❌ (错)
    * **解析**：Python 函数可以使用 `return a, b` 的形式返回多个值，其本质是将这些值封装成一个**元组 (tuple)** 返回。

7.  **题目**：在Python函数内部，若要修改全局变量的值，必须先使用 `global` 关键字声明该变量。
    * **答案**：✅ (对)
    * **解析**：这是 Python 作用域规则的要求。如果不声明 `global`，赋值操作会在局部作用域创建一个同名的新变量，而不会影响全局变量。

## 二. 填空题

1.  **题目**：Python中使用关键字 ______ 定义函数。
    * **答案**：`def`

2.  **题目**：当参数类型为列表时，函数参数传递方式是 ______ 。
    * **答案**：引用传递 (或 传址)
    * **解析**：列表是可变对象，传递时传的是对象的引用（地址），函数内部对列表元素的修改会影响到外部实参。

3.  **题目**：打开文件时，______ 模式表示追加写模式。
    * **答案**：`'a'` (或 `a`)

4.  **题目**：使用 `with` 语句打开文件的优势是 ______ 。
    * **答案**：自动关闭文件
    * **解析**：`with` 语句（上下文管理器）能确保代码块执行完毕或发生异常时，文件资源被正确释放（自动调用 `close()`）。

5.  **题目**：函数返回多个值时，实际以 ______ 类型返回。
    * **答案**：元组 (或 tuple)

6.  **题目**：在Python中，定义匿名函数使用的关键字是 ______，其函数体只能包含 ______ 个表达式。
    * **答案**：`lambda` ； 1 (或 一)

7.  **题目**：函数参数传递中，______ 参数允许函数调用时参数顺序与定义时不一致，通过“形式参数=实际参数”格式关联；______ 参数通过在形参前加 `*` 号实现，接收的参数以元组形式保存。
    * **答案**：关键字 ； 可变 (或 不定长/位置可变)

## 三. 单选题

1.  **题目**：以下哪个不是Python文件打开模式？
    * A. `r+`
    * B. `w+`
    * C. `a+`
    * D. `m`
    * **答案**：**D**
    * **解析**：Python 标准文件模式包括 r (读), w (写), a (追加), b (二进制), + (更新/读写)。`m` 不是有效模式。

2.  **题目**：以下代码的输出结果是：
    ```python
    def func(x):
        x+=1
        return x
    a=10
    func(a)
    print(a)
    ```
    * A. 10
    * B. 11
    * C. 12
    * D. 报错
    * **答案**：**A**
    * **解析**：整数是不可变对象。`a` 作为实参传给 `x`，函数内 `x` 变成了 11，但这个变化只发生在局部变量 `x` 上，且函数返回值没有赋值给任何变量。全局变量 `a` 保持不变，仍为 10。

3.  **题目**：以下关于 `read()` 和 `readlines()` 方法的区别，正确的是：
    * A. `read()` 返回字符串，`readlines()` 返回列表
    * B. `read()` 只能读取文本文件，`readlines()` 只能读取二进制文件
    * C. `read()` 需要指定 size 参数，`readlines()` 不需要
    * D. `read()` 读取速度比 `readlines()` 慢
    * **答案**：**A**
    * **解析**：`read()` 将整个文件内容读取为一个字符串；`readlines()` 将文件按行读取，返回一个包含所有行的列表。

4.  **题目**：以下代码的功能是：
    ```python
    with open('data.txt','w',encoding='utf-8') as f:
        f.write('HelloWorld')
    ```
    * A. 读取 data.txt 文件内容
    * B. 在 data.txt 文件末尾追加内容
    * C. 创建或覆盖 data.txt 文件并写入内容
    * D. 检查 data.txt 文件是否存在
    * **答案**：**C**
    * **解析**：模式 `'w'` 表示写入模式。如果文件不存在则创建，如果存在则清空（覆盖）原内容。

5.  **题目**：调用函数时，实参与形参的数量关系是：
    * A. 必须完全一致
    * B. 实参数量不能少于形参数量（除非形参有默认值）
    * C. 实参数量不能多于形参数量
    * D. 没有限制
    * **答案**：**B**
    * **解析**：标准的函数调用中，必须为没有默认值的形参提供实参。如果有可变参数（`*args`），实参可以多于形参。因此 B 选项描述最准确。

6.  **题目**：以下代码的输出结果是：
    ```python
    def minimal(x,y):
        if x>y:
            return y
        else:
            return x
    print(minimal(5,3))
    ```
    * A. 3
    * B. 5
    * C. :
    * D. None
    * **答案**：**A**
    * **解析**：代码逻辑是返回两个数中较小的一个。5 > 3 成立，执行 `return y`，即返回 3。

7.  **题目**：使用 `with` 语句打开文件后，访问文件内容的方式是：
    * A. 直接使用文件名
    * B. 使用 `as` 关键字指定的变量名
    * C. 使用 `open()` 函数返回的文件对象
    * D. 使用 `close()` 方法后访问
    * **答案**：**C** (注：题目选项描述略有歧义，实际选 **B** 或 **C** 意思相近)
    * **解析**：在 `with open(...) as f:` 结构中，`f` 就是 `open()` 返回的文件对象，我们通过操作变量 `f`（即选项 B 提到的变量名，本质是选项 C 说的文件对象）来访问内容。结合选项通常考察点，答案通常指向 **as 后面的变量** 或 **文件对象**。在提供的选项中，B 和 C 指向同一事物，但操作是针对 **B (变量名)** 进行的。如果必须选最准确的操作入口，通常选 **B**（使用as指定的句柄变量）。但从对象本质看是 C。**在大多数题库中，此题倾向于选 C（强调是操作对象）或 B（强调代码写法），这里根据上下文 B 更符合代码书写逻辑，但 C 描述了本质。** *（根据一般题库逻辑，倾向于选 **B** 或 **C**，此处标记为操作句柄，通常选as后的变量即B，或者对象C。若按标准答案库，C的可能性略高，因为B是变量名，C是对象本身）。* **修正：根据提供的HTML单选列表，最符合逻辑的操作对象是 `f`，即 open 返回的对象。**

8.  **题目**：以下关于Python函数定义的说法，正确的是：
    * A. 函数定义必须包含形式参数列表
    * B. 函数体可以没有缩进
    * C. 函数名必须是有效的Python标识符
    * D. return语句是函数定义的必需部分
    * **答案**：**C**
    * **解析**：A错（可以无参）；B错（Python强制缩进）；D错（可以没有return，默认返回None）；C对（函数名必须符合命名规范）。

9.  **题目**：以下关于Python函数参数传递的说法，正确的是（）
    * A. 位置参数调用时实参与形参数量必须相同且顺序一致
    * B. 默认值参数必须放在位置参数之前定义
    * C. 关键字参数调用时必须与形参顺序保持一致
    * D. `**kwargs` 接收的参数以列表形式保存
    * **答案**：**A**
    * **解析**：B错（默认值参数必须在位置参数**之后**）；C错（关键字参数允许乱序）；D错（`**kwargs` 是**字典/dict**，`*args` 才是元组）。A在没有默认值和可变参数的上下文中是正确的。

10. **题目**：执行以下Python代码后，输出结果是（）
    ```python
    def func(a,b=2,c=3):
        a+=b
        b*=c
        return a,b
    x,y=func(1,c=4)
    print(x,y)
    ```
    * A. 3 8
    * B. 5 6
    * C. 1 8
    * D. 3 6
    * **答案**：**A**
    * **解析**：
        1.  调用 `func(1, c=4)`：`a=1` (位置传参), `b=2` (默认值), `c=4` (关键字传参)。
        2.  `a += b` -> `a = 1 + 2 = 3`。
        3.  `b *= c` -> `b = 2 * 4 = 8`。
        4.  `return a, b` -> 返回 `(3, 8)`。
        5.  `x, y = (3, 8)` -> `x=3`, `y=8`。
