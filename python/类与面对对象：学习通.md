# Python 面向对象编程 (OOP) 练习题与解析

## 一、单选题

**1. 以下代码中，`self` 的作用是？**

```python
class Car:
    def set_color(self, color):
        self.color = color
```

- A. 代表类 Car 本身
- B. 代表当前对象实例
- C. 是一个保留字
- D. 用于定义静态方法

> **正确答案：B**
>
> **解析：** 在 Python 的类方法中，第一个参数（通常命名为 `self`）指的是调用该方法的当前对象实例。通过 `self.color = color`，我们将属性绑定到了具体的实例上，而不是类本身。

**2. 在类中定义实例属性的通常位置是？**

- A. `__init__` 方法中
- B. 类定义的外部
- C. 普通方法中
- D. 全局变量中

> **正确答案：A**
>
> **解析：** 虽然可以在任何方法中定义实例属性，但在 `__init__`（构造方法）中定义是规范的做法。这样可以确保对象一旦创建，就具备了所有必要的属性初始化。

**3. 在 Python 中，创建类的实例的正确方式是？**

- A. `MyClass()`
- B. `new MyClass()`
- C. `MyClass.create()`
- D. `MyClass.init()`

> **正确答案：A**
>
> **解析：** Python 实例化对象不需要 `new` 关键字（这是 Java 或 C++ 的写法）。直接像调用函数一样调用类名 `ClassName()` 即可触发 `__init__` 方法并创建实例。

**4. 类的构造方法的特殊名称是？**

- A. `__start__`
- B. `__create__`
- C. `__init__`
- D. `__main__`

> **正确答案：C**
>
> **解析：** `__init__` 是 Python 中的初始化方法（构造函数），在创建新对象时会自动调用。

**5. 以下关于类和对象的关系，描述正确的是？**

- A. 类是对象的实例
- B. 对象是类的模板
- C. 类是对象的模板，对象是类的实例
- D. 类和对象没有关系

> **正确答案：C**
>
> **解析：** 类（Class）是抽象的模板或蓝图，定义了结构和行为；对象（Object）是根据这个模板创建出来的具体实体（实例）。

**6. 以下哪个是 Python 类定义的正确语法？**

- A. `class MyClass{}`
- B. `class MyClass:`
- C. `def MyClass()`
- D. `new MyClass()`

> **正确答案：B**
>
> **解析：** Python 使用冒号 `:` 来开启一个代码块，而不是花括号 `{}`。选项 A 是 Java/C++ 风格；选项 C 是定义函数的语法。

**7. 执行以下代码后，输出结果是？**

```python
class Person:
    def __init__(self, name):
        self.name = name
        
p = Person("Alice")
print(p.name)
```

- A. Person
- B. Alice
- C. name
- D. 报错

> **正确答案：B**
>
> **解析：** 创建 `Person` 实例时传入了 `"Alice"`，它被赋值给实例属性 `self.name`。打印 `p.name` 即输出 `"Alice"`。

**8. 以下关于 `self` 参数的描述，正确的是？**

- A. `self` 是 Python 的关键字
- B. `self` 必须作为类中所有实例方法的第一个参数
- C. `self` 代表类本身
- D. `self` 可以省略不写

> **正确答案：B**
>
> **解析：**
> - A 错：`self` 只是约定俗成的命名，并非关键字。
> - B 对：定义实例方法时，第一个参数必须存在以接收实例对象。
> - C 错：`cls` 通常用来代表类本身。
> - D 错：在定义实例方法时不能省略。

## 二、判断题

**1. 在类的方法中，可以不使用 `self` 参数访问实例属性。**

> **答案：错误 (False)**
>
> **解析：** 在类内部，访问实例属性必须通过 `self.变量名`，否则 Python 会将其视为局部变量或全局变量。

**2. 类的构造方法 `__init__` 必须显式定义，否则无法创建对象实例。**

> **答案：错误 (False)**
>
> **解析：** 如果不定义 `__init__`，Python 会提供一个默认的构造方法，依然可以创建对象。

**3. Python 中类名的命名规范通常采用驼峰命名法（首字母大写）。**

> **答案：正确 (True)**
>
> **解析：** 根据 PEP 8 规范，类名应使用 PascalCase（大驼峰命名法），如 `MyClass`。

**4. 同一个类的不同实例，其属性值是相互独立的。**

> **答案：正确 (True)**
>
> **解析：** 实例 A 的 `name` 修改不会影响实例 B 的 `name`。

**5. 类的方法必须在类内部定义，不能在类定义后动态添加。**

> **答案：错误 (False)**
>
> **解析：** Python 是动态语言，可以在运行时向类或实例动态添加方法（虽然不建议频繁这样做）。

**6. 创建类的实例时，构造方法 `__init__` 会自动被调用。**

> **答案：正确 (True)**
>
> **解析：** 这是构造函数的主要作用。
