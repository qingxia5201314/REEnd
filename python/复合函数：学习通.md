# Python 列表与元组 (List & Tuple) 完整习题集

## 一、填空题 (共6题)

1. 题目：列表的索引从______开始，最后一个元素的索引是______。
   - 答案：0 ； -1
   - 解析：Python 索引从 0 开始计数；负数索引 -1 代表序列的最后一个元素。

2. 题目：列表的______方法可以用于向列表末尾添加元素，______方法可以用于删除列表中指定索引位置的元素。
   - 答案：append ； pop (或 del 语句)
   - 解析：append() 在末尾追加单个对象；pop(index) 移除并返回指定索引处的元素。

3. 题目：列表的______方法可以用于对列表进行排序，而______方法可以用于对列表进行逆序排列。
   - 答案：sort ； reverse
   - 解析：sort() 使列表按升序排列；reverse() 将列表中的元素原地翻转。

4. 题目：使用______函数可以将字符串转换为列表，例如：list('hello') 的结果是______。
   - 答案：list ； ['h', 'e', 'l', 'l', 'o']
   - 解析：list() 函数将可迭代对象的每个元素拆分并组成新列表。

5. 题目：在 Python 中，创建元组使用______符号。创建一个包含整数3、字符串'abc'、列表[0, 1, 2]的元组，应写为______。
   - 答案：() (或小括号) ； (3, 'abc', [0, 1, 2])
   - 解析：元组使用小括号定义，内部可以存储不同类型的混合数据。

6. 题目：列表的切片操作格式为 list[start:end:step]，其中 start 表示起始索引，end 表示______，step 表示______。
   - 答案：结束索引（不包含） ； 步长
   - 解析：切片遵循“左闭右开”原则，不包括 end 索引指向的元素。

## 二、单选题 (共8题)

1. 题目：下列关于列表和元组的说法中，哪一项是正确的？
   [A] 列表和元组都不可变
   [B] 列表不可变，元组可变
   [C] 列表可变，元组不可变
   [D] 列表和元组都可变
   - 正确答案：C
   - 解析：列表是动态的、可变的；元组一旦创建，其元素不可更改。

2. 题目：以下代码执行后，输出的结果是什么？
   list_one = [1, 2, 3]
   list_two = list_one
   list_two.clear()
   print(list_one)
   [A] [1, 2, 3]
   [B] []
   [C] [1, 2]
   [D] [3]
   - 正确答案：B
   - 解析：list_two = list_one 是引用赋值。清空 list_two 实际上清空了它们共同指向的内存对象。

3. 题目：在 Python 中，下列哪个选项是合法的列表创建方式？
   [A] list_one = {1, 2, 3}
   [B] list_one = (1, 2, 3)
   [C] list_one = [1, 2, 3]
   [D] list_one = 1, 2, 3
   - 正确答案：C
   - 解析：列表使用方括号 []；A是集合或字典，B和D是元组。

4. 题目：以下代码执行后，变量 x 的值是什么？
   x = [1, 2, 3]
   x[1:2] = [4, 5]
   [A] [1, 4, 5, 3]
   [B] [1, 2, 3]
   [C] [4, 5]
   [D] [1, 4, 3]
   - 正确答案：A
   - 解析：切片赋值会将索引 1 处的元素替换为 [4, 5] 中的内容，导致列表长度增加。

5. 题目：以下代码执行后，输出的结果是什么？
   list_one = [1, 2, 3, 4]
   list_two = list_one
   list_one[1] = 99
   print(list_two[1])
   [A] 1
   [B] 2
   [C] 99
   [D] 4
   - 正确答案：C
   - 解析：由于引用关系，修改 list_one 的同时也影响了 list_two。

6. 题目：下列关于嵌套列表的说法中，哪一项是正确的？
   [A] 嵌套列表只能包含整数
   [B] 嵌套列表可以包含列表、元组、字典等多种数据类型
   [C] 嵌套列表只能包含字符串
   [D] 嵌套列表不能包含其他列表
   - 正确答案：B
   - 解析：Python 列表是通用容器，可以嵌套任何其他数据对象。

7. 题目：下列代码中，哪一个是正确的元组创建方式？
   [A] tuple_one = [1, 2, 3]
   [B] tuple_one = (1, 2, 3)
   [C] tuple_one = {1, 2, 3}
   [D] tuple_one = 1, 2, 3
   - 正确答案：B
   - 解析：最标准的显式元组定义方式是使用小括号 ()。

8. 题目：以下代码执行后，输出的结果是什么？
   list_one = [1, 2, 3]
   list_two = list_one.copy()
   list_one.append(4)
   print(list_two)
   [A] [1, 2, 3, 4]
   [B] [1, 2, 3]
   [C] [4]
   [D] [1, 2, 3, 3]
   - 正确答案：B
   - 解析：copy() 方法创建了一个新的独立对象。修改原列表不会影响副本。

## 三、判断题 (共6题)

1. 题目：使用 del 语句可以删除列表中的某个元素。
   - 答案：正确 (True)
   - 解析：del list[index] 是 Python 中删除列表特定位置元素的常用方式。

2. 题目：列表的索引是从 1 开始的。
   - 答案：错误 (False)
   - 解析：Python 所有序列类型的索引均从 0 开始。

3. 题目：元组和列表一样，都是可变的数据类型。
   - 答案：错误 (False)
   - 解析：元组一旦定义，其成员不能再增、减或重新赋值。

4. 题目：列表的 append() 方法可以在列表的任意位置插入元素。
   - 答案：错误 (False)
   - 解析：append() 仅限末尾；在任意位置插入应使用 insert(index, obj)。

5. 题目：列表的切片操作不会改变原列表。
   - 答案：正确 (True)
   - 解析：切片操作会生成并返回一个新的列表对象，除非它是作为左值被赋值。

6. 题目：元组可以包含列表作为元素。
   - 答案：正确 (True)
   - 解析：元组可以包含任何对象。虽然元组本身不可变，但如果内部包含列表，该列表的内容是可以被修改的。
