# 期末复习

## 1. MySQL约束 (Constraints)
**核心考点**：掌握建表时的语法，以及每个约束对数据完整性的作用。

- **NULL / NOT NULL (空/非空约束)**
  - 作用：规定字段是否可以为空。主键默认是非空的。
- **DEFAULT (默认值约束)**
  - 作用：当插入数据未指定该字段值时，使用默认值。
- **COMMENT (注释)**
  - 作用：为字段添加说明，不影响逻辑，但利于维护。
- **ZEROFILL (零填充)**
  - 作用：配合整型使用，长度不足时左侧补0（如 `001`）。
- **PRIMARY KEY (主键约束)**
  - 作用：**唯一**标识一条记录，**非空**且**唯一**。一张表只能有一个主键。
- **AUTO_INCREMENT (自增长约束)**
  - 作用：系统自动分配递增的序列号，通常配合主键使用。
- **UNIQUE KEY (唯一约束)**
  - 作用：保证字段值不重复（允许为空 NULL）。
- **FOREIGN KEY (外键约束)**
  - 作用：保持数据一致性，将当前表与父表主键关联。

> **代码示例**：
> ```sql
> CREATE TABLE student (
>     id INT PRIMARY KEY AUTO_INCREMENT,
>     name VARCHAR(20) NOT NULL,
>     phone VARCHAR(11) UNIQUE KEY,
>     class_id INT,
>     FOREIGN KEY (class_id) REFERENCES class(id)
> );
> ```

## 2. 数据库设计的六个基本步骤
**核心考点**：简答题常考，需背诵顺序。

1. **需求分析阶段**：分析用户需求（产出数据流图、数据字典）。
2. **概念结构设计阶段**：将需求转化为 **E-R 图**（实体-联系图）。
3. **逻辑结构设计阶段**：将 E-R 图转换为**关系模式**（数据库表），进行范式规范化。
4. **物理设计阶段**：选择存储引擎、索引策略等。
5. **数据库实施阶段**：编写 SQL 建库建表，载入数据。
6. **数据库运行和维护阶段**：性能优化、备份、安全管理。

- **特点**：数据以**表**的形式存储，通过公共字段建立联系。

## 4. MySQL的七个查询语句 (书写 vs 执行)
**核心考点**：**执行顺序**是选择题和面试的重灾区。

| 关键字 | 含义 | 书写顺序 | **执行顺序 (重点)** |
| :--- | :--- | :--- | :--- |
| **FROM** | 数据来源 | 2 | **1** |
| **WHERE** | 分组前过滤 | 3 | **2** |
| **GROUP BY** | 分组 | 4 | **3** |
| **HAVING** | 分组后过滤 | 5 | **4** |
| **SELECT** | 选择列 | 1 | **5** |
| **ORDER BY** | 排序 | 6 | **6** |
| **LIMIT** | 限制行数 | 7 | **7** |

> **注意**：`WHERE` 不能接聚合函数（sum, avg），`HAVING` 可以。

## 5. MySQL的数据类型
- **数值类型**：`INT` (整数), `DECIMAL` (定点数/金额), `FLOAT` (浮点)。
- **日期和时间类型**：`DATE` (日期), `DATETIME` (日期时间), `TIMESTAMP` (时间戳)。
- **字符串类型**：`CHAR` (定长/快), `VARCHAR` (变长/省空间), `TEXT` (长文本)。
- **枚举与集合类型**：`ENUM` (单选), `SET` (多选)。
- **空间数据类型**：GIS相关类型（考试较少涉及）。

## 6. 事务的四大特性 (ACID)
**核心考点**：必须背诵定义的关键词。

- **原子性 (Atomicity)**：事务是最小单位，要么全部成功，要么全部失败（回滚）。
- **一致性 (Consistency)**：事务前后数据状态保持守恒/一致。
- **隔离性 (Isolation)**：一个事务不应被其他事务干扰（涉及脏读、幻读）。
- **持久性 (Durability)**：事务提交后，修改是永久的（写入磁盘）。

## 7. 数据库表关系
- **一对一 (1:1)**
  - 实现：外键放在任意一方，并设为 `UNIQUE`。
- **一对多 (1:N)**
  - 例子：班级 -> 学生。
  - 实现：**外键放在“多”的一方**（学生表存班级ID）。
- **多对多 (N:M)**
  - 例子：学生 <-> 课程。
  - 实现：**必须创建第三张“中间表”**，包含两个表的主键作为联合主键。

## 8. SQL 实战演练 (基于 emp/dept 表)

### 8.1 限制查询 (LIMIT) - 分页查询
> **考点**：`LIMIT 起始下标, 长度`。注意下标从 0 开始。

```sql
-- 1. 查找emp中的所有信息，按hiredate升序排序，从第5条记录开始共6条
SELECT * FROM emp ORDER BY hiredate ASC LIMIT 4, 6;

-- 2. 查找emp中的所有信息，按sal降序排序，取前5名
SELECT * FROM emp ORDER BY sal DESC LIMIT 5;
-- 3. 查找“最高薪”和“最低薪”
SELECT MAX(sal) AS 最高薪, MIN(sal) AS 最低薪 FROM emp;

-- 4. 查找“所有人平均年薪”和“所有人的总年薪” (假设sal为月薪)
SELECT AVG(sal*12) AS 平均年薪, SUM(sal*12) AS 总年薪 FROM emp;

-- 5. 查找empno列的记录数 (总人数)
SELECT COUNT(empno) FROM emp;
-- 6. 查找每个部门的：部门号，部门平均工资，部门最高工资
SELECT deptno, AVG(sal), MAX(sal) FROM emp GROUP BY deptno;

-- 7. 多重分组：按部门号分组的基础上，再按工作类别分组
SELECT deptno, job, AVG(sal), MAX(sal) FROM emp GROUP BY deptno, job; -- 这里为什么要分组呢？因为deptno和job是列，avg(sal),max(sal)是一个数值，这两个有不确定性，不能一一对应，所以需要分组来确定每个部门和工作的平均工资和最高工资

-- 8. 分组后过滤：查找平均工资小于2000的部门
SELECT deptno, AVG(sal) FROM emp 
GROUP BY deptno 
HAVING AVG(sal) < 2000;

-- 9. 综合排序：查找部门平均工资 > 2000 的部门，并按平均工资降序排序
SELECT deptno, AVG(sal) AS avg_sal 
FROM emp 
GROUP BY deptno 
HAVING avg_sal > 2000 
ORDER BY avg_sal DESC;
-- 10. 查找 ename, dname 信息 (笛卡尔积/隐式内连接)
SELECT e.ename, d.dname FROM emp e, dept d WHERE e.deptno = d.deptno;

-- 11. 标准内连接：查找 ename, sal, dname, deptno
SELECT e.ename, e.sal, d.dname, e.deptno 
FROM emp e 
JOIN dept d ON e.deptno = d.deptno;

-- 12. 连接后过滤：查找部门号=10的 dname, ename, sal, deptno
SELECT d.dname, e.ename, e.sal, e.deptno 
FROM emp e 
JOIN dept d ON e.deptno = d.deptno 
WHERE e.deptno = 10;

-- 13. 连接后排序：先按部门号排序，再按工资排序
SELECT e.ename, e.sal, d.dname 
FROM emp e 
JOIN dept d ON e.deptno = d.deptno 
ORDER BY e.deptno, e.sal;

-- 14. 自连接：查找员工名字和他上司的名字
SELECT e.ename AS 员工, m.ename AS 上司 
FROM emp e 
JOIN emp m ON e.mgr = m.empno;
-- 15. 查找最高工资员工的信息 (标量子查询)
SELECT * FROM emp WHERE sal = (SELECT MAX(sal) FROM emp);

-- 16. 查找大于平均工资的所有员工信息
SELECT * FROM emp WHERE sal > (SELECT AVG(sal) FROM emp);

-- 17. 查找 'SMITH' 所在部门的所有员工名字
SELECT ename FROM emp 
WHERE deptno = (SELECT deptno FROM emp WHERE ename = 'SMITH');

-- 18. IN 子查询：查找工作类型在部门10中有的员工，但排除部门10本身的员工
SELECT * FROM emp 
WHERE job IN (SELECT job FROM emp WHERE deptno = 10) 
AND deptno != 10;

-- 19. 相关子查询 (难点)：查找比【本部门】平均工资高的员工
-- 解析：将外表 e1 的 deptno 传给内表 e2 进行过滤
SELECT * FROM emp e1 
WHERE sal > (
    SELECT AVG(sal) FROM emp e2 WHERE e2.deptno = e1.deptno
);
```

## 9. 索引 (Index)
**概念**：
索引相当于书籍的**目录**。它是一种特殊的数据结构（如 B+树），帮助数据库系统快速找到对应的数据行，而无需扫描整个表。

**作用 (优缺点)**：
* **优点 (Why use it)**：
    * **极大加快查询速度**（最主要的作用）。
    * 唯一性索引可以保证数据库表中每一行数据的唯一性。
    * 加速表和表之间的连接（JOIN）。
    * 在使用分组（GROUP BY）和排序（ORDER BY）时，显著减少时间。
* **缺点 (Cost)**：
    * **占用物理空间**：索引文件需要存储在磁盘上。
    * **降低增删改速度**：当执行 `INSERT`、`UPDATE`、`DELETE` 时，数据库不仅要修改数据，还要维护索引树，导致性能下降。

**常见类型**：
* 普通索引 (Normal)
* 唯一索引 (Unique)
* 主键索引 (Primary Key)
* 全文索引 (Fulltext)
* 组合索引 (多列索引)

## 10. 约束：主键与外键 (PK & FK)
**核心区别与联系**：

| 特性 | **主键 (Primary Key)** | **外键 (Foreign Key)** |
| :--- | :--- | :--- |
| **定义** | 唯一标识表中的一条记录。 | 用于建立两个表之间的联系。 |
| **唯一性** | 值必须**唯一**。 | 值可以**重复**。 |
| **空值** | **不允许为空 (NOT NULL)**。 | **允许为空 (NULL)**（除非额外指定）。 |
| **数量** | 一个表**只能有一个**主键 (可以是复合主键)。 | 一个表可以有**多个**外键。 |
| **作用** | 保证自身数据的完整性。 | 保证参照完整性 (Referential Integrity)。 |
| **关系** | 通常是“父表”的身份证。 | 通常在“子表”中引用父表的主键。 |

> **考试口诀**：主键是“身份证号”（一人一个，不能丢），外键是“籍贯代码”（指向另一个标准的表，可以重复，可以空着）。

## 11. 数据库备份的分类
备份通常可以从**物理/逻辑**、**在线/离线**、**备份量**三个维度来划分。

### 11.1 按备份策略/量划分 (最常考)
1.  **完全备份 (Full Backup)**
    * 备份整个数据库的所有数据。
    * *特点*：恢复最快，但备份时间长，占用空间大。
2.  **差异备份 (Differential Backup)**
    * 备份自**上一次完全备份**之后有变化的数据。
    * *特点*：备份速度中等，恢复时需要“全备+最后一次差备”。
3.  **增量备份 (Incremental Backup)**
    * 备份自**上一次备份**（无论是全备、差备还是增备）之后有变化的数据。
    * *特点*：备份最快，占用空间最小，但恢复最麻烦（需要按顺序还原所有备份链）。

### 11.2 按备份实现方式划分
1.  **物理备份**
    * 直接复制数据库的物理文件（如 `.ibd` 文件, log 文件）。
    * *工具*：Xtrabackup, cp/tar 命令。
    * *特点*：速度极快，适合大数据量。
2.  **逻辑备份**
    * 将数据导出为 SQL 语句（CREATE, INSERT）。
    * *工具*：`mysqldump`。
    * *特点*：速度慢，文件可读，适合跨版本/跨平台迁移。

### 11.3 按数据库状态划分
1.  **冷备份 (Cold/Offline Backup)**
    * **关机**备份。停止数据库服务后拷贝文件。
    * *特点*：最安全，但业务会中断。
2.  **热备份 (Hot/Online Backup)**
    * **开机**备份。数据库运行中进行备份，不影响读写。
    * *特点*：需要专业工具支持（如 InnoDB 引擎支持热备），业务不中断。

## 基础查询实战

**1. 查询所有员工的姓名和工资**
```sql
SELECT ename, sal FROM emp;
```

**2. 查询所有员工的姓名，工作和入职日期，并按入职日期降序排序**
```sql
SELECT ename, job, hiredate 
FROM emp
```

```sql
SELECT * FROM emp WHERE deptno = 30;
```

```sql
SELECT ename, sal FROM emp WHERE sal > 2000;
```

```sql
SELECT ename, job 
FROM emp 
WHERE job IN ('MANAGER', 'ANALYST');
```

**6. 查询姓名以 'S' 开头的员工信息**
> *注：通常数据库区分大小写，若名字是大写存储请用 'S%'*

```sql
SELECT * FROM emp WHERE ename LIKE 'S%';
```

**7. 查询没有佣金(comm)的员工姓名和佣金**

```sql
SELECT ename, comm FROM emp WHERE comm IS NULL;
```

```sql
SELECT ename, sal 
FROM emp 
WHERE sal BETWEEN 1000 AND 2000;
```

**9. 查询所有部门的名称**
```sql
SELECT dname FROM dept;
```

**10. 查询员工总数**
```sql
SELECT COUNT(*) AS 员工总数 FROM emp;
```

## 多表连接查询实战

**1. 查询每个员工的姓名、部门编号和部门名称**
> *考点：标准内连接 (Inner Join)*
```sql
SELECT e.ename, e.deptno, d.dname 
FROM emp e 
JOIN dept d ON e.deptno = d.deptno;
```

**2. 查询部门所在地为 'DALLAS' 的所有员工姓名**
> *考点：连接查询 + WHERE 过滤*
```sql
SELECT e.ename 
FROM emp e 
JOIN dept d ON e.deptno = d.deptno 
WHERE d.loc = 'DALLAS';
```

**3. 查询每个员工的姓名、工资以及对应的工资等级**
> *考点：非等值连接 (Non-Equi Join)，连接条件不是相等，而是区间*
```sql
SELECT e.ename, e.sal, s.grade 
FROM emp e 
JOIN salgrade s ON e.sal BETWEEN s.losal AND s.hisal;
```

**4. 查询 'SALES' 部门的所有员工姓名和工资**
```sql
SELECT e.ename, e.sal 
FROM emp e 
JOIN dept d ON e.deptno = d.deptno 
WHERE d.dname = 'SALES';
```

**5. 查询工资等级为 4 的所有员工姓名和工资**
```sql
SELECT e.ename, e.sal 
FROM emp e 
JOIN salgrade s ON e.sal BETWEEN s.losal AND s.hisal 
WHERE s.grade = 4;
```

**6. 查询每个员工的姓名、工资、部门名称以及工资等级**
> *考点：多表联合 (3张表连接)*
```sql
SELECT e.ename, e.sal, d.dname, s.grade 
FROM emp e 
JOIN dept d ON e.deptno = d.deptno 
JOIN salgrade s ON e.sal BETWEEN s.losal AND s.hisal;
```

**7. 查询员工 'KING' 所在部门的所有员工信息**
> *考点：自连接 (Self-Join) 或 子查询。此处展示自连接写法*
```sql
SELECT e1.* FROM emp e1 
JOIN emp e2 ON e1.deptno = e2.deptno 
WHERE e2.ename = 'KING';
```

**8. 查询每个部门的部门名称和该部门的员工人数**
> *考点：连接 + 分组 (GROUP BY) + 聚合函数*
```sql
SELECT d.dname, COUNT(e.empno) AS 员工人数 
FROM dept d 
JOIN emp e ON d.deptno = e.deptno 
GROUP BY d.dname;
```

**9. 查询每个部门的部门名称和该部门的平均工资**
```sql
SELECT d.dname, AVG(e.sal) AS 平均工资 
FROM dept d 
JOIN emp e ON d.deptno = e.deptno 
GROUP BY d.dname;
```

**10. 查询员工人数多于 3 人的部门名称和员工人数**
> *考点：分组后的过滤 (HAVING)*
```sql
SELECT d.dname, COUNT(e.empno) AS 员工人数 
FROM dept d 
JOIN emp e ON d.deptno = e.deptno 
GROUP BY d.dname 
HAVING COUNT(e.empno) > 3;
```
