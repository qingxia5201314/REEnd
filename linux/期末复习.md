# 🐧 Linux 系统管理期末复习重点

## 1. 基础文件与目录操作
- **进入上一级目录**
  - 命令：`cd ..`
- **查看内容但不打开编辑器**
  - 命令：`cat filename.txt`
  - *注意：不能对目录使用 cat 命令。*
- **赋予脚本执行权限**
  - 命令：`chmod +x script.sh`

## 2. 用户与组管理
- **创建用户并指定 UID 和组**
  - 命令：`useradd -u 1500 -G wheel tom`
  - **参数解析**：
    - `-u 1500`：指定 UID。
    - `-G wheel`：指定**附加组** (Supplementary Group)。*注意：原笔记 "whell" 拼写错误。*
    - `-g`：用于指定**主组** (Primary Group)。
- **用户认证日志**
  - 位置：通常记录在 `/var/log/secure` (RHEL/CentOS) 或 `/var/log/auth.log` (Debian/Ubuntu)。
  - *注意：原笔记 "i昂管" 为 "相关" 的拼写错误。*

## 3. 网络配置与管理
- **监控网络连接**
  - 命令：`netstat`
  - 功能：监控网络连接、路由表、接口统计信息等。
- **查看/配置网卡信息**
  - 命令：`ifconfig`
- **关键配置文件 (易混淆考点)**
  - `/etc/hosts`：用于储存 **IP 与主机名** 的静态映射关系。
  - `/etc/resolv.conf`：用于储存 **DNS 服务器** 的 IP 地址。
- **虚拟机网络模式**
  - **Bridged (桥接模式)**：让虚拟机获得独立 MAC 地址并直接参与物理局域网。

## 4. Vim 编辑器模式
- **三种基本模式**：
  1. **普通模式 (Normal Mode)**：默认进入，用于导航和删除。
  2. **插入模式 (Insert Mode)**：普通模式下按 `i` 进入，用于打字。
  3. **命令行模式 (Command-line Mode)**：普通模式下按 `:` (冒号) 进入，用于保存退出 (`wq`)。

## 5. Syslog 日志优先级 (Severity Levels)
> **核心原则**：数值越**小**，优先级越**高** (越严重)。

| 数值 | 关键词 | 含义 |
| :--- | :--- | :--- |
| 0 | emerg | 紧急 (系统不可用) |
| ... | ... | ... |
| 3 | err | 错误 |
| 4 | warning| 警告 |
| ... | ... | ... |
| 6 | info | 一般信息 |
| 7 | debug | 调试信息 |

- **考点纠错**：
  - “数值小于 info (6) 的是 debug” —— **错误**。Debug 是 7，数值比 info 大。数值小于 6 的是 notice, warning, err 等更严重的级别。
  - “warning 的等级低于 err” —— **正确**。Warning (4) 的严重性确实低于 Error (3)。
